# Glitz Pride concept demo

An isolated, presentation-only mockup for a premium gated villa community. It includes illustrative property content and a deterministic assistant demonstration that runs entirely in the browser.

## View locally

Open `dist/index.html` in a browser, or serve the `dist` folder with any static web server.

## Important

All names, prices, specifications, availability, locations and contacts are dummy content. No form data is transmitted or stored. Temporary reference imagery must be replaced with owner-approved assets before any commercial publication.
